# Brick, Mortar & Plaster Calculator

A lightweight and easy-to-use calculator to help builders, architects, and DIY enthusiasts estimate the required quantities of bricks, mortar, and plaster for construction projects.

## Features
- Calculate number of bricks needed for walls
- Estimate mortar required for brickwork
- Compute plaster quantities for walls and ceilings
- Works with different wall dimensions and plaster thicknesses
- Ideal for quick construction estimations
